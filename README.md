# HackPodz
Mini HackTheBox-like application with vulnerable training containers built for a USMA CY394 group project.

CDT Dinono created most of the vulnerable containers, while I created the web-application portion largely re-using previous projects.

The final application was built using rancher and was fully functional, but has since been taken down as the class has ended.
(all secret keys are meaningless, but need to be changed if used in production again)
